# Универ Серийчек 🔥

Кроссплатформенная PWA-версия приложения для iPhone и Android.

## Установка

Открой опубликованную страницу в браузере и выбери «Добавить на экран Домой» / «Установить приложение».

## Публикация

GitHub Actions публикует содержимое папки `web/` в GitHub Pages автоматически при изменениях.

## Синхронизация

Для общего прогресса между устройствами настрой бесплатный проект Supabase и выполни SQL из `SUPABASE_SETUP.md`. В веб-приложении укажи только публичный anon/publishable key. Никогда не помещай `service_role` key в браузер.
