# Универ Серийчек 🔥

Кроссплатформенная PWA-версия приложения для iPhone и Android.

## Что внутри
- ежедневные отметки посещения по геолокации;
- огоньки, уровни и серия посещений;
- календарь, статистика и достижения;
- настройка кампуса, радиуса и учебного расписания;
- локальное сохранение и офлайн-кэш;
- резервная копия данных: экспорт и импорт;
- необязательная облачная синхронизация между устройствами через Supabase.

## Установка
Открой опубликованную страницу в Safari или Chrome и выбери «Добавить на экран Домой» / «Установить приложение».

## Публикация
GitHub Actions проверяет JavaScript и manifest, затем публикует содержимое папки `web/` в GitHub Pages.

## Синхронизация между iPhone и Android
1. Создай бесплатный проект Supabase.
2. Выполни SQL из `SUPABASE_SETUP.md` в SQL Editor.
3. В приложении открой Профиль и введи Project URL и публичный anon/publishable key.
4. Создай аккаунт и используй тот же аккаунт на втором устройстве.

**Важно:** в браузер нельзя вставлять `service_role` key. Используй только публичный anon/publishable key с включённой RLS.

## Ограничения
- Для геолокации требуется HTTPS и разрешение браузера.
- Браузерная геолокация не гарантирует защиту от подмены GPS или системного времени.
- Без входа в Supabase данные хранятся локально на текущем устройстве.
